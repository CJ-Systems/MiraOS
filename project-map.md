# MiraOS Project Map

MiraOS is early public documentation, not packaged software. This repository presents the project thesis, documentation system, and emerging architecture.

## Start Here

| If you want to understand... | Read... | Why |
|---|---|---|
| The project thesis | `README.md` | Explains what MiraOS is trying to become and why it exists. |
| Current project state | `STATUS.md` | Captures the current public-documentation phase, active work, and explicit non-goals. |
| Which project document to create | `docs/active-templates/Routing_Guide.md` | Routes ideas, decisions, research, reviews, and status into the right artifact type. |
| Template maturity | `docs/active-templates/README.md` | Shows which templates are settled now and which are still under review. |
| The full generated template catalog | `docs/templates/README.md` | Source/reference catalog preserved for comparison and later adaptation. |

## Repository Layers

### Public Root

The root files are the public entry points.

- `README.md` - project thesis and framing.
- `STATUS.md` - current project snapshot.
- `LICENSE` - repository license.

### Active Documentation

`docs/active-templates/` contains the MiraOS-specific templates currently being shaped for project use. Its README tracks which templates are ready and which are still under review.

### Source Catalog

`docs/templates/` contains the full generated template pack. It is the source catalog behind the smaller active template set.

### Reference Notes

Some MiraOS notes may synthesize standards, research, experiments, or other source material that is not included in this repository.

The repository includes original project analysis and implications, not copyrighted standards text or protected source material.

## Current State

This repository does not yet provide a stable installable runtime, finalized requirements, or complete architecture docs.
