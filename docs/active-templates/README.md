# MiraOS Active Templates

This folder contains MiraOS-specific working templates. Some are ready for active use; others are drafted here so they can be reviewed and refined against real MiraOS needs.

The generated catalog in `docs/templates/` remains the source/reference catalog. Copy or derive active templates here rather than editing the generated source templates directly.

## Template Maturity

### Ready / Active Now

- `Code_Review_Record.md` — used for meaningful code changes, AI-assisted development handoffs, and learning-focused reviews.

### Drafted / Under Review

- `Research_Note.md` — captures source-grounded learning before it becomes a decision, requirement, or design.
- `Routing_Guide.md` — decides which document type to create when new MiraOS project knowledge appears.
- `Spike_Report.md` — records bounded technical experiments and their evidence.
- `Standard_Note.md` — companion markdown map for one standard or formal guide without copying protected text.
- `Topic_Map.md` — cross-topic navigation across docs, standards, code, and open questions.
